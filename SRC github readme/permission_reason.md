If you're reading this, you’re likely wondering why PocketMark is requesting "access to all folders and files" permission. I understand that this permission might seem excessive, so here is a brief explanation of why it is necessary:

The permission is required primarily for two functions:

1. Custom Home Folders: This allows you to change the app's home directory in the settings. Without it, the app cannot navigate your file system or create the necessary media folders in your chosen destination.

2. ZIP Exports: To make the Export to .zip feature work, Android requires this permission so the app can gather multiple files and compress them into a single archive.

If, after reading this, you are still uncomfortable granting this permission, I completely understand. Please feel free to uninstall the app. No hard feelings! I only ask to not leave a negative review for a requirement that is ultimately a technical necessity.
